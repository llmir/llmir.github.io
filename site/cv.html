Research Experience

CATL Hong Kong Research Institute (HKRI)

Nov 2025 – Present

Senior AI Engineer

Recursive Self-Improvement (RSI) and Automated Agent Harness Optimization

I study how execution traces can inform automated harness revisions. I use controlled evaluations across successive revisions to measure cross-task transfer, regression, and whether improvements are sustained across iterations.

Multi-Agent AutoResearch Frameworks

I develop multi-agent frameworks that coordinate hypothesis development, experimental design, and independent verification for materials research. Applications include machine-learned force fields, materials property prediction, and screening.

Multimodal, generalizable AI for battery characterization

I develop advanced signal processing and multimodal AI methods for ultrasonic measurements, scanning electron microscopy (SEM), and other characterization modalities. I study how representations of battery state and microstructure generalize across cells, instruments, and measurement conditions.

The University of Hong Kong

Sep 2021 – Sep 2025

Doctoral Researcher, OMEGA Lab · Joint PhD training with SUSTech MedICAL Lab

My research in medical imaging and computer vision spans my doctorate and subsequent collaborations.

Data- and annotation-efficient learning

I develop methods that learn from scarce, incomplete, or noisy supervision and imbalanced data. This work combines anatomy-guided synthesis, prototype-based pseudo-label calibration, and semi-supervised adaptation to make better use of unlabeled scans and underrepresented cases.

Cross-domain generalization and adaptation

I study how imaging models transfer across acquisition domains and annotation protocols. My work includes learned augmentation for unseen domains, complementary teachers for adaptation to multiple unlabeled targets, and anatomy-aware prompting for supervision at different levels of detail.

Personalized federated learning across data silos

I developed personalized federated learning methods for institutions with heterogeneous imaging distributions and weak annotations. Site-aware representation learning, shared and local prompts, and adaptive aggregation or distillation let institutions share knowledge while retaining models suited to their own data.

Multimodal representation learning and foundation models

I study transferable representations through masked modeling of 2D and 3D scans, complementary MRI pretraining, and image–report alignment. Related work addresses noisy image–text correspondence and grounds medical vision–language reasoning in clinical knowledge graphs.

Image synthesis and reconstruction

I work on recovering or synthesizing complementary information when acquisitions differ in contrast, resolution, or spatial alignment. Open Research

Datasets and Benchmarks

  • HROCT-Bench / UniOCTSeg++

    IEEE TMI 2026

    A retinal OCT layer segmentation benchmark spanning 11 datasets and eight annotation granularities. The release includes six preprocessed subsets and split files. The repository provides data access instructions and supervised and semi-supervised training scripts.

    Open subsets · Code and data guide · PaperPaper

  • YoloCurvSeg Benchmark Data

    MedIA 2023

    Five prepared benchmarks for weakly supervised vessel and nerve segmentation, with dense masks, noisy skeleton labels, and documented data splits. The release supports comparisons across annotation budgets and imaging domains.

    Data and splits · PaperPaper

  • SUSTech–SYSU

    Scientific Data 2020

    1,219 fundus photographs with exudate annotations, optic disc boxes, fovea locations, and diabetic retinopathy grades from three protocols. The shared annotations support lesion detection and comparisons across grading conventions.

    Dataset · Annotation guide · PaperPaper

Research Implementations and Models

  • EyeGraph

    IEEE TMI 2026

    Vision–language pretraining and instruction-tuning code for retinal image interpretation, with a knowledge-graph reasoning module for report generation and a recorded demonstration.

    Code · Demo video · PaperPaper

  • MF-MCM

    Information Fusion 2026

    Complementary masked pretraining for learning from multiple MRI sequences. The implementation includes pretraining, fine-tuning, and 3D evaluation for brain tumor segmentation.

    Code · PaperPaper

  • DRAgent

    Research Square 2026 · Preprint

    A multidisciplinary agent implementation for studying treatment planning in diabetic retinopathy. The repository includes specialist agents, an evaluation split, and quantitative scoring scripts.

    Code · PaperPaper

  • MIRAGE

    MedIA 2026

    Medical image–text pretraining under noisy pairings. The repository provides data preparation, training configurations, and objectives for reducing the effect of mismatched image–report pairs.

    Code · PaperPaper

  • AniMer+ / AniMer

    IEEE TPAMI 2026 · CVPR 2025

    Family-aware reconstruction of animal pose and shape from a single image. The project page shows predictions for mammals and birds, and both versions provide training and evaluation code.

    Project page · AniMer+ code · AniMer code · AniMer+AniMer+ · AniMerAniMer

  • ProCNS

    IEEE JBHI 2025

    Progressive prototype calibration and noise suppression for segmentation from sparse annotations. The release provides processed data links and training and evaluation commands.

    Code · PaperPaper

  • FedLPPA / FedICRA

    IEEE TMI 2025 · MLMI at MICCAI 2023

    Personalized federated segmentation across sites with different imaging distributions and weak labels. Both implementations document data preparation, client settings, and training and evaluation.

    FedLPPA code · FedICRA code · FedLPPAFedLPPA · FedICRAFedICRA

  • PRIOR

    ICCV 2023

    Prototype-based local and global alignment of medical images and reports. The repository includes the pretraining implementation and a released ResNet-50 image encoder.

    Code · Encoder weights · PaperPaper

  • AADG

    IEEE TMI 2022

    Automatic augmentation search for domain generalization in retinal image segmentation. The repository includes policy search, training, and evaluation code for studying transfer to unseen acquisition domains.

    Code · PaperPaper
